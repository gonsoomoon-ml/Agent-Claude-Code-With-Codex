핵심 요약
- Anthropic은 Claude Fable 5.2와 Mythos 5.2 발표 글에서 두 모델이 같은 기반 모델이라고 밝혔습니다. Fable은 사이버보안과 생물학 안전장치를 붙여 모든 사용자에게, Mythos는 Cyber 또는 Life Sciences Verification Program에 신청해 승인된 기관에게 제공합니다.
- API 가격은 입력 100만 토큰당 $8, 출력 $40입니다. 원문은 Fable 5.1과 Mythos 5.1보다 가격이 낮고 출력이 최대 30% 빠르다고 설명하며, 선택 기능인 fast mode는 최대 2.5배 빠른 대신 입력 $16, 출력 $80입니다.
- Anthropic이 직접 측정한 FrontierCode 2.0에서 Fable 5.2는 Xhigh 추론 강도로 49.1%를 기록해 Opus 5.5(45.5%), GPT-6 Astra(42.8%)보다 높습니다. 다만 AutomationBench는 Gemini 4 Carbon(53.9%)이, AA-Briefcase의 Elo는 Opus 5.5(1800)가 더 높습니다.
- 에이전트 약 1,000개가 페르마의 마지막 정리를 30시간 만에 Lean으로 형식화했고, 같은 설정의 Opus 5.5는 18시간 시점에 26%였습니다. 이 사례와 물리, 단백질, 전자 설계 사례는 모두 Anthropic과 협력 기관이 전한 결과입니다.
- 가속기 커널 최적화와 LLM 아키텍처 개선 영역은 학습 단계에서 능력 향상을 제한해 Opus 5.5 수준으로 맞췄다고 합니다. 안전장치의 차단은 Fable 5.1 대비 약 55% 줄었습니다.
